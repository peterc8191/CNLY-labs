# CNLY Labs website

Marketing site for CNLY Labs, a software development studio. Built with React 19 and Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run preview  # preview the build
```

- Site copy (services, work, process, contact details): `src/data.js`
- Styles and colour tokens: `src/styles.css`
- Logo (vector recreation): `src/components/Logo.jsx`, original artwork in `public/brand/`
